الكفاية الإملائية: أعراف الكتابة وعلامات الترقيم

تطبيق مراجعة شروحات وتدريبات مادة الكفايات اللغوية

أولاً: أعراف الكتابة السبعة

عادات تعارف عليها الكُتّاب لتنظيم المادة المكتوبة ومساعدة القارئ على الفهم والتركيز[cite: 1].

1. العناوين (الرئيسة والجانبية)

توضع العناوين الرئيسة بوسط الأعلى والتفصيلات بعناوين جانبية يمين الصفحة[cite: 1].

مثال: العنوان الرئيسي لدرس، والعناوين الجانبية للأقسام.[cite: 1]

2. إبراز الكلمات ذات الأهمية

تمييز الكلمات الهامة بلون مختلف، أو خط تحتها، أو تغيير نوع الخط وحجمه لتنبيه القارئ[cite: 1].

3. التعداد

تنظيم التفصيلات بأساليب التعداد (لفظي، رقمي، ألفبائي، أبجدي، أو نقطي)[cite: 1].

4. الكتابة في فقرات

تبدأ كل فقرة بفراغ بمقدار كلمة وتنتهي بنقطة، وتعبر كل فقرة عن فكرة رئيسة واحدة[cite: 2].

5. استخدام الجداول والرسوم

تلخيص التفصيلات الكثيرة وإعطاء القارئ تصوّراً شاملاً للموضوع[cite: 2].

6. تحديد الأهداف

افتتاح الفصل بالنتائج والأهداف المأمولة لتركيز ذهن القارئ ومساعدته[cite: 2].

7. التلخيص

اختتام الفصول بملخص يوجز أهم ما ورد فيها لإعطاء فرصة مراجعة مركزة[cite: 2].

ثانياً: مواضع علامات الترقيم

النقطة ( . )

توضع في نهاية الجملة التي اكتمل معناها تماماً[cite: 3].

العلمُ صيدٌ والكتابةُ قيدُه.[cite: 3]

النقطتان الرأسيتان ( : )

بعد القول، بين الشيء وأقسامه، وبعد كلمة (مثل)[cite: 3].

قال عليٌّ: «العلم نهرٌ»[cite: 3]

الفاصلة ( ، )

بين المفردات/الجمل المتعاطفة، أقسام الشيء، وبعد المنادى وقبل (مثل)[cite: 3].

يا عبدَ الله، اسمع النصيحة.[cite: 3]

الفاصلة المنقوطة ( ؛ )

بين جملتين بينهما علاقة سببية (إحداهما سبب للأخرى)[cite: 4].

ذاكرَ الطالبُ بجدٍّ؛ فنجحَ بتفوق.[cite: 4]

الشرطة ( - )

بين طرفي الجملة الطويلة، في الحوارات بديل الأسماء، وبعد الأعداد[cite: 4].

1- أولاً | - متى عدت؟ - أمس.[cite: 4]

الشرطتان ( - - )

يوضع بينهما الكلام المعترض في أصل الجملة[cite: 5].

كان أبوك - رحمه الله - رجلاً فاضلاً.[cite: 5]

القوسان ( ( ) )

لتفسير جملة/كلمة غامضة، أو حصر الأرقام في وسط الكلام[cite: 5].

الصبر (عصارة نبات مر) دواء.[cite: 5]

علامتا التنصيص ( « » )

يحصر بينهما الكلام المنقول بنصه تماماً[cite: 5].

قال الرسول: «إنما الأعمال بالنيات».[cite: 5]

علامة الاستفهام ( ؟ )

توضع بعد الجمل الاستفهامية بجميع أنواعها[cite: 5].

علامة التأثر/التعجب ( ! )

نهاية الجمل الانفعالية (تعجب، دعا، تمني، مدح، ذم)[cite: 6].

علامة الحذف ( ... )

مكان الكلام المحذوف للدلالة على بقية لم تُذكر[cite: 6].
