الكفاية الإملائية: أعراف الكتابة وعلامات الترقيم

تطبيق مراجعة وتدريبات تفاعلية لمادة الكفايات اللغوية

أولاً: أعراف الكتابة السبعة

1. العناوين (الرئيسة والجانبية)

يوضع العنوان الرئيس بوسط أعلى الصفحة، والتفصيلات بعناوين جانبية يمين الصفحة.

2. إبراز الكلمات ذات الأهمية

تمييز الكلمات المهمة بلون مختلف، أو تحتها خط، أو بتغيير حجم الخط ونوعه.

3. التعداد

ترتيب الجزئيات بالتعداد اللفظي، الرقمي، الألفبائي، الأبجدي، أو النقطي.

4. الكتابة في فقرات

تبدأ كل فقرة بفراغ بمقدار كلمة وتنتهي بنقطة، وتعبر عن فكرة رئيسة واحدة.

5. استخدام الجداول والرسوم

تلخيص التفصيلات الكثيرة وإعطاء القارئ تصوراً كلياً شاملاً للموضوع.

6. تحديد الأهداف

افتتاح الفصول بالأهداف المتوقع تحقيقها لتركيز انتباه القارئ ومساعدته.

7. التلخيص

اختتام الفصول بملخص موجز يساعد القارئ على التركيز والمراجعة السريعة.

ثانياً: مواضع علامات الترقيم

النقطة ( . )

توضع في نهاية الجملة التي اكتمل معناها تماماً.

مثال: العلمُ نورٌ.

النقطتان الرأسيتان ( : )

بعد القول وشبهه، بين الشيء وأقسامه، وبعد كلمة (مثل).

مثال: قال عليٌّ: «العلمُ نهرٌ».

الفاصلة ( ، )

بين الجمل المتعاطفة، بين أقسام الشيء، وبعد المنادى.

مثال: يا عبدَ الله، اجتهد.

الفاصلة المنقوطة ( ؛ )

تقع بين جملتين بينهما علاقة سببية (سبب أو نتيجة).

مثال: ذاكرتُ؛ فنجحتُ.

الشرطة ( - )

في الحوارات بديل الأسماء، بين طرفي الجملة الطويلة، وبعد الأعداد.

مثال: 1- التفسير.

الشرطتان ( - - )

يوضع بينهما الكلام المعترض في أصل الجملة.

مثال: كان النبي - صلى الله عليه وسلم - عادلاً.

القوسان ( ( ) )

توضيح كلمة غامضة، أو حصر الأرقام في وسط الكلام.

مثال: الفقرة (ب) من المادة (5).

علامتا التنصيص ( « » )

يحصر بينهما الكلام المنقول بنصه حرفياً.

مثال: قال الرسول: «إنما الأعمالُ بالنيات».

علامة التأثر ( ! )

نهاية الجمل الانفعالية (تعجب، دعا، تمني، مدح، ذم).

مثال: ما أجملَ الصدقَ!

علامة الحذف ( ... )

توضع مكان الكلام المحذوف للدلالة على البقية.

مثال: دواوين الشعراء كزهير والمهلهل...
